# Car Race (prototype)

Browser time-attack racing prototype aiming at realistic driving physics. Cycle 1: physics test bed (flat ground, top-down view).

- All cars, names and designs are fictional and not affiliated with any real manufacturer.
- - Physics: 4-wheel planar model, tire slip curve with load sensitivity, load transfer, gearbox, LSD, ABS/TC assists. Fixed 1/240 s step (deterministic).
  - - Automatic measurements: open the page with ?test=1.
    - - Planned: city scenery based on PLATEAU 3D city model (MLIT). Attribution will be added when used: "Source: MLIT PLATEAU website, modified by the author".
